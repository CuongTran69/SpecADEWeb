HTTP CLIENT

HTTP client tương thích Postman, ngay trong cửa sổ chứa code của bạn.

Tạo collections, folders và requests; đổi environment và biến bí mật; stream response qua SSE kèm huỷ giữa chừng. Import từ curl hoặc Postman Collection v2.1, export ngược ra — không cần công cụ API riêng.

Tương thích Postman

Import và export Postman Collection v2.1 cùng environment. Cả import từ lệnh curl — dán vào là thành request.

Collections & environments

Nhiều workspace, cây Collections → Folders → Requests, kèm biến environment và biến bí mật lưu tách biệt.

Thực thi SSE-streaming

Stream status, headers, body và timing theo thời gian thực; huỷ request giữa chừng bất kỳ lúc nào.

Lịch sử theo workspace

500 request gần nhất mỗi workspace được lưu lại, biến được resolve ngay tại thời điểm gửi.

PORT FORWARDING

Truy cập dev server hay admin UI local ngay qua workspace.

Một reverse proxy tích hợp tại `/fw/{port}` chuyển tiếp lưu lượng HTTP và WebSocket tới bất kỳ cổng nào trên máy đang chạy Spec ADE. Xem trước dev server, mở admin UI database, hay gọi API local ngay trên cùng host mà workspace của bạn đang chạy — hop-by-hop headers được xử lý đúng chuẩn.

Dịch vụ local localhost:5173 Vite dev server
Đường proxy →
Spec ADE /fw/5173/ HTTP + WebSocket upgrade
Mở trong trình duyệt →
Browser https://ade-host/fw/5173/ 200 OK

Reverse proxy tích hợp

Handler catch-all `/fw/{port}/{*rest}` chuyển tiếp thẳng tới cổng bất kỳ trên máy chạy Spec ADE — không cấu hình thêm.

HTTP + WebSocket

Hỗ trợ cả request HTTP thường lẫn nâng cấp WebSocket, nên dev server có hot-reload vẫn hoạt động qua proxy.

Hop-by-hop đúng chuẩn

Lọc các header hop-by-hop theo RFC 7230 để proxy trong suốt, không làm hỏng kết nối keep-alive.

Tiện khi tự-host

Chạy Spec ADE trên một máy remote rồi xem admin UI database hay dev server của máy đó ngay trong trình duyệt.
