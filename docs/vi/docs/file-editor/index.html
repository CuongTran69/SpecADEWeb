Soạn thảo File

Spec ADE có editor mã nguồn tích hợp với cây file bên trái. Bạn có thể duyệt thư mục, mở file, sửa, lưu — tương tự một IDE quen thuộc.

Cây File

Khu file tree nằm ở bên trái. Cây hiển thị cấu trúc thư mục, lọc theo .gitignore của dự án, và bỏ qua node_modules, .git, cache — để cây gọn nhẹ.

Duyệt & mở

Click mở/đóng folder. Double-click file để mở chính thức. Right-click cho menu (rename, delete, copy path, open in terminal).

Tìm kiếm

Ô tìm trên đầu tree để lọc theo tên file. Cây tự thu gọn chỉ hiển thị nhánh khớp.

Tạo & quản lý

Right-click “New File” hoặc “New Folder”. Rename, delete, move to trash — tất cả cập nhật ngay trên đĩa.

Lưu & Tab

Ctrl+S (Windows/Linux) hoặc ⌘S (macOS) để lưu. File tự lưu khi bạn rời tab. Tab file có dấu chấm khi chưa lưu. Kéo-thả tab để sắp xếp. Right-click để đóng.

Preview Media

Ảnh, video, audio, PDF đều có preview tích hợp. File Markdown có chế độ xem render và chế độ sửa raw text (toggle bằng Ctrl+K).
