Cài đặt Spec ADE

Cài Spec ADE trên máy hoặc VPS dưới 1 phút.

Cài đặt

Sẵn sàng dưới một phút

Một lệnh duy nhất để cài Spec ADE trên máy hoặc VPS của bạn.

Lần đầu chạy, Spec ADE hiển thị machine ID (dạng ADE-xxx ). Gửi cho team support viber.vn để nhận key kích hoạt.

Đã chính thức phát hành @spec-ade/cli trên npm. Chạy lệnh bên dưới để cài đặt và sử dụng ngay lập tức.

Cài đặt và chạy (macOS, Windows, Linux) 
npx -y @spec-ade/cli@latest
Cài đặt trên VPS / Cloud Server 
npx -y @spec-ade/cli@latest --host 0.0.0.0 --port 3100

Trên VPS, CLI sẽ in URL — bạn mở từ browser local.

Spec ADE serve cả API và SPA embedded trên cùng port. Không cần web server riêng.

Sau khi chạy, Spec ADE tự mở trên trình duyệt của bạn.
Chưa cài npm/npx?

Spec ADE cần Node.js 22 trở lên.

macOS

brew install node@22

hoặc truy cập nodejs.org

Linux

curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs

Ubuntu/Debian. Với RHEL/Fedora xem hướng dẫn NodeSource RHEL.

Windows

winget install OpenJS.NodeJS

hoặc tải installer tại nodejs.org
