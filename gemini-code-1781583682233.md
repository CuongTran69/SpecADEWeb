## 1. Spec ADE là gì — bản định nghĩa mới

**Spec ADE = Agentic Development Environment** — một workspace local-first được thiết kế để AI coding agents làm việc có kiểm soát.

Nói ngắn hơn:

> **Spec ADE là buồng lái local cho AI coding agents:** terminal, git, database console và nhiều agent chạy song song trong một workspace, khởi chạy siêu tốc chỉ bằng một lệnh `npx`.

Không nên định vị Spec ADE là “IDE tốt hơn Cursor”. Cách đó rất khó thắng vì Cursor/Zed/VS Code đã có hệ sinh thái editor mạnh.

Nên định vị Spec ADE là:

> **Control plane cho agent làm việc ở local.**

Tức là nơi dev có thể:

- chạy agent,
- xem agent làm gì,
- kiểm tra terminal/log,
- review git diff,
- check database,
- chạy nhiều agent song song,
- giữ workflow ở local thay vì phụ thuộc hoàn toàn vào cloud.

### Đặc điểm kỹ thuật hiện có

| Nhóm | Mô tả |
|---|---|
| Kiến trúc | Rust backend + Vue 3 frontend |
| Phân phối | Chạy trực tiếp qua `npx -y @spec-ade/cli@latest`, không cần cài đặt app |
| Local-first | Workspace chạy trên máy người dùng |

### One-liner mới

## 2. Bối cảnh thị trường AI coding tools năm 2026

### 2.1. Thị trường đã chuyển từ autocomplete sang agentic workflow

Năm 2026, AI coding không còn chỉ là gợi ý code theo dòng. Các tool lớn đều đang đi về hướng agent:

- **Cursor**: IDE AI-native, agent trong editor, background/SDK agents, Bugbot, review, design mode.
- **Claude Code**: CLI agent mạnh, subagents, skills, hooks, MCP, context/config theo repo.
- **GitHub Copilot**: editor agent mode + cloud agent trên GitHub, làm việc background trên branch/PR.
- **OpenAI Codex**: coding agent cho macOS/Windows, IDE extension, Codex Cloud.
- **Devin / Devin Desktop**: autonomous SWE agent + hướng command center quản lý nhiều agent.
- **Cline / Roo / Aider**: nhóm open-source / BYOK / terminal-extension agent, mạnh ở control và tùy biến.

### 2.2. Các nhóm tool hiện tại

| Nhóm | Ví dụ | Giá trị chính | Điểm yếu thường gặp |
|---|---|---|---|
| AI IDE / Editor-attached agent | Cursor, Zed, VS Code + Copilot | UX editor tốt, inline diff, quen tay | vẫn chủ yếu xoay quanh editor, khó gom DB/Git/terminal/agent farm thành một runtime thống nhất |
| CLI / terminal agent | Claude Code, Codex CLI, Aider | mạnh cho refactor, repo tasks, automation | review diff/undo/context switching có thể bất tiện với dev không thích terminal-only |
| Extension agent / BYOK | Cline, Roo Code | tùy biến provider, kiểm soát model/cost tốt hơn | chi phí token khó đoán, setup phức tạp hơn |
| Cloud autonomous agent | Devin, Copilot cloud agent, Codex Cloud | giao task chạy background, PR-oriented | code/data đi lên cloud/sandbox, phụ thuộc provider, khó debug runtime local |
| Agent command center | Devin Desktop, Cursor agents, GitHub Agent HQ | quản lý nhiều agent/task | thường gắn vào hệ sinh thái/plan/cloud riêng |
| **Spec ADE** | **Spec ADE** | **local cockpit cho agent: terminal + git + DB + multi-agent chạy thẳng qua npx** | cần chứng minh bằng demo, còn brand mới |

### 2.3. Nỗi đau thị trường đã rõ hơn

File cũ tập trung vào “phải mở 5–6 app”. Pain này vẫn đúng, nhưng chưa đủ. Hiện tại dev còn đau ở những điểm sâu hơn:

1. **Control** — agent tự sửa nhiều file, nhưng dev không biết nó đang dựa vào context nào.
2. **Cost** — Claude Code/Cline/Cursor/Codex đều có câu chuyện chi phí, quota, token hoặc plan khác nhau.
3. **Reviewability** — dev cần xem diff, undo, kiểm tra terminal/test/log nhanh, không muốn nhảy qua 3 app.
4. **Local vs cloud** — enterprise/team nhạy cảm với source code, secrets, database, repo private.
5. **Parallel work** — chạy nhiều agent song song đang thành nhu cầu thật, nhưng UX quản lý vẫn rối.
6. **Trust** — AI code có thể chạy được nhưng chưa chắc đúng, sạch, maintainable. Dev cần workflow kiểm soát chứ không chỉ “generate code”.

=> Vì vậy messaging mới nên chuyển từ:

> “Bạn đang mở quá nhiều tool.”

sang:

> “Bạn không thiếu AI agent. Bạn thiếu một buồng lái để kiểm soát agent.”
